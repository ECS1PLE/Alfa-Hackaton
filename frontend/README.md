# Альфа-Бизнес

Next.js-приложение по HTML-макетам из `../design`. React, TypeScript, App Router и CSS Modules.

## Запуск

```bash
npm run dev
```

Приложение доступно на [localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run lint
npm run build
```

## Структура

- `app` — маршруты и метаданные страниц.
- `src/screens` — сборка 11 экранов из компонентов.
- `src/components/UI` — настраиваемые каркасы карточек, кнопок, меток, таблиц и других элементов.
- `src/components` — компоненты оболочки, компании, инсайтов, аналитика и внутренних экранов.
- `src/providers` — выбранная компания и настройки ленты.
- `src/hooks` — сохранение состояния в браузере.
- `src/data` — типизированные демо-данные из макетов.
- `src/types`, `src/utils` — типы и функции отбора событий.
- `src/styles` — общие стили макетов и адаптивная раскладка.

## Экраны

`/`, `/feed`, `/event?id=e1`, `/chat`, `/profile`, `/sources`, `/trace`, `/settings`, `/clients`, `/quality`, `/architecture`.

Ссылки из HTML-прототипа с расширением `.html` перенаправляются на соответствующие маршруты Next.js с сохранением параметров.

## Демо-режим

Компании, новости, аналитика, ответы чата, журнал агента и метрики перенесены из прототипа. Backend и реальная LLM не подключены. Исходных PDF и внешних документов в макетах нет, поэтому кнопки источников ведут к записям каталога.

Выбор компании, настройки, интересы, уточнения контекста и оценки разборов сохраняются в `localStorage`. Порог значимости, показ возможностей и рекламных предложений применяются к интерфейсу. Настройки уведомлений и группы компаний сохраняются как демо-предпочтения; рассылки и пересчёт моделей не выполняются.
